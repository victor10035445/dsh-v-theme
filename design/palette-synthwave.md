# V 调色板 · 赛博霓虹变体库（NEON Variants）

> 来源：赛博霓虹 '84（现行 Miami 基线）的色彩延展研究，2026-09。
> **更名说明**：赛博霓虹进阶版已更名为**赛博霓虹**（NEON，主题 id 仍为 `neon`）；概念叙事层见 `concept-layer.md`。
> 用途：dsh-v-theme 赛博霓虹主题的**备选配色方案库**——每个变体 = 一份 `PALETTE_*` 常量 + FX 层色值替换，架构零改动。
> 约束（与 palette-tactical.md 同源）：**背景族令牌禁入**（交还 DSH 原生深色底），一切表达只在强调/边框/文字/状态层发生。

---

## 0 · 真实底色基准（对比度计算地板）

DSH 原生深色基底（已对当前安装产物核实，README 的「紫夜空 #141126」描述已过时）：

| 变量 | 色值 | 角色 |
|---|---|---|
| bg-base | `#151517` | 页面底 |
| bg-layer-1 | `#232324` | 一级卡片 |
| bg-layer-2 | `#2c2c2e` | 二级表面 |

所有变体的对比度按这三档实测（WCAG 相对亮度公式）。项目约定：正文 ≥7:1、次文 ≥4.5:1、UI 强调 ≥3:1（状态色力争 7:1）。

## 2 · 通用规则（全变体继承）

1. **两类「绿」严格分开**：会话**完成框体/状态点恒定 `#00FF88`**（FX 层字面量，跨主题语义锚点，与 Tactical 同源——官方成功语义与完成框体在基线本就是两个对象）；调色板 `--dsw-alias-state-success-primary` 为官方成功语义色，随案可变（各表「success 语义」行），**不进会话框体**。
2. **金色审批通道**：`#FFC857` 六案通用——「该你了」的语义锚点不动摇。
3. **alpha 阶梯不变**：辉光 .08–.15、hover .4、sev 底 .14–.20、氛围光 .04–.10。
4. **切换即换装**：每个变体在 `THEMES` 注册表加条目（palette + fx + swatch），热替换机制零改动。
5. **shiki 代码高亮**随变体换端点色：keyword=primary、function/constant=secondary、string=tertiary 系。
6. 反模式清单（palette-tactical.md 第 7 节）全变体适用；额外一条：**霓虹粉在任何变体中不得既做主色又做 error 色**（基线 A 用 #FF3B5C 区分，F 案倒置后尤其注意）。

## 3 · 选择指南

| 场景 | 推荐 |
|---|---|
| 忠于现行、粉蓝对撞 | A Miami（基线） |
| 要「赛博霓虹海报」的完整日落色带 | B Outrun |
| 夜间长会话、柔和不刺眼 | C Vaporwave |
| 冷感氛围、深空夜航 | D Neon Violet（primary 用提亮版 #C07CFF） |
| 金属质感、千禧怀旧 | E Y2K Chrome |
| 白天办公、专业克制 | F Blue Nocturne |

落地成本：每案 = 一个 `PALETTE_*` 常量（≈50 个令牌值）+ FX 层内色值替换（渐变端点/辉光/shiki 表）+ swatch 三色点。不新增选择器、不动架构。
